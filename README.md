# Store Rating System 🛒⭐

The **Store Rating System** is a full-stack web application where users can **rate stores**, **view feedback**, and **analyze store performance**.  
It provides **role-based dashboards** for **users**, **store owners**, and **admins**.

---

## 🚀 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- Sequelize ORM
- JSON Web Token (JWT)
- bcrypt for password hashing

### Database
- PostgreSQL

---

## ✨ Features

- 🔑 **User Authentication** (Sign up, Login, Password update)
- 🧑 **Roles**: Normal User, Store Owner, Admin
- 📊 **Dashboards**:
  - **User Dashboard** → View & give ratings
  - **Owner Dashboard** → Manage store & see ratings
  - **Admin Dashboard** → Manage users & system
- 🔒 **Secure Passwords** with hashing & validation
- 🎨 **Modern UI** with responsive design
